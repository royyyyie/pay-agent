# 阶段 7：生产加固与灰度检查清单

阶段目标：将阶段 0～6 的工程能力放入可审计、可排空、可回滚的多副本部署，并用 Staging 真实报告决定是否进入只读生产灰度。仓库自动化不能替代云资源、业务流量和审批人产生的外部事实。

## 第一批：进程生命周期与部署安全基线

- [x] 新增最小存活探针 `/livez`，不访问外部依赖、不返回环境或连接信息
- [x] 新增 `/readyz`，在排空或关键持久化/RAG 依赖不可用时失败关闭
- [x] `/api/` 全响应生命周期计数，SSE 在最后一个响应块完成前持续计入在途请求
- [x] 终止时停止准入、有界等待在途请求、关闭外部客户端并输出生命周期指标
- [x] Uvicorn 单一配置 Bootstrap 与有界 graceful shutdown
- [x] Uvicorn 收到终止信号时立即进入排空，并设置进程级并发硬上限
- [x] 非 root、只读根文件系统、全部 Capability drop、RuntimeDefault seccomp
- [x] 双副本、零不可用滚动更新、PDB、拓扑分散、资源 requests/limits
- [x] 配置与 Secret 分离；示例 Secret 不包含真实凭据，交易功能默认关闭
- [x] 有界只读压测脚本只输出聚合指标，不输出请求正文、响应正文或凭据
- [x] 生命周期、部署资产和探针自动化测试

## 第二批：供应链与安全门禁

- [ ] CI 构建镜像并以不可变 digest 发布，生成 SBOM 和来源证明
- [ ] 镜像、Python 依赖、Secret 和 IaC 扫描达到零 Critical/High 未豁免项
- [ ] 完成威胁模型联合评审，所有 High 风险有负责人、截止时间和验证证据
- [ ] 验证 NetworkPolicy、云防火墙、出站域名代理、数据库最小权限与 Secret 轮换
- [ ] 验证日志、Trace、审计和告警均无 Prompt、购票人、证件、密钥或完整 Tool Payload

## 第三批：Staging 容量、故障与灰度

- [ ] 在与生产同拓扑的 Staging 持续压测至少 30 分钟，保存吞吐、成功率、P50/P95/P99、CPU、内存和连接池报告
- [ ] 注入 Provider、Java Gateway、Redis、PostgreSQL、Elasticsearch、Kafka 和实例强杀故障
- [ ] 验证扩缩容、滚动更新、节点驱逐和排空超时；重复副作用及未知写入盲重放均为 0
- [ ] 完成备份恢复、数据库迁移回滚、知识索引回滚和应用版本回滚演练
- [ ] 阶段 3～6 的外部验收证据全部归档并绑定提交、镜像 digest、配置版本和时间窗
- [ ] 安全、SRE、业务、交易负责人批准只读灰度；订单写能力保持关闭
- [ ] 按 1% → 5% → 25% → 50% → 100% 分档，每档至少观察一个约定窗口并满足 SLO

## 退出红线

- 未授权 Tool 成功数、跨租户成功数、重复订单数、未知写入盲重放数、PII/Secret 泄漏数必须全部为 0。
- 任一关键 SLO 超阈、证据缺失或审批过期，立即停止放量并回滚。
- 阶段 7 只有在第二、三批及阶段 3～6 遗留外部验收全部完成后，才能标记为“企业生产准入完成”。

执行顺序见[阶段 7 灰度与回滚 Runbook](phase-7-operations.md)，风险清单见[阶段 7 威胁模型](phase-7-threat-model.md)。
